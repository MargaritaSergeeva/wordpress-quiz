# Проверка основы проекта

Дата: 2026-09-17.

- SSH-доступ к GitHub и подключение `origin` проверены.
- Репозиторий публичный.
- `docker compose config --quiet` — успешно.
- `php -l scripts/bootstrap.php` — успешно.
- `php -l wp-content/plugins/wordpress-quiz/wordpress-quiz.php` — успешно.
- `.env` исключён из Git через `.gitignore`.

Полная установка и HTTP-проверка локального WordPress пока **не выполнены**:
загрузка официальных образов прерывается сетевыми ошибками Docker Hub
(`TLS handshake timeout`, `EOF`), в том числе при повторной попытке.
После восстановления доступа выполнить `make install`, проверить вход в админку,
активацию плагина и повторный запуск установки без изменения данных.

Это проверка каркаса проекта, а не результаты тестирования готового квиза.
